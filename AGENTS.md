# AGENTS.md — Memory Log

## Назначение
Локальный трекер активности для Windows (Rust workspace + Tauri): записывает активные окна/программы и показывает сводку дня с опциональной синхронизацией через Google Drive.

## Структура
- `crates/` — Rust-крейты ядра и трекера.
- `app/` — Tauri-приложение.
- `config/` — конфигурация.
- `docs/` — документация.

## Команды проверки
```powershell
cargo test --workspace
cargo build --release --workspace
```

## Правила
- Не коммитить локальные данные, токены и содержимое `pass/`.
- Соблюдать privacy-first модель: данные по умолчанию хранятся локально на ПК пользователя.
