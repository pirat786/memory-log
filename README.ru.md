# Memory Log

[English](README.md) · **Русский**

Локальная «память компьютера» для Windows: тихо записывает, чем вы занимались за день, и показывает
понятную сводку. По умолчанию данные остаются на вашем ПК. Для личных устройств можно отдельно
включить синхронизацию через Google Drive.

## Возможности

- **Сводка дня**: активное время, на что оно ушло (работа, общение, соцсети, игры…), главные занятия,
  ритм дня (перерывы, переключения между программами), цели на день, обзор недели.
- **Шкала дня**: цветной отрезок открывает список окон за этот период, маркер ведёт к закладке.
  Подсчёт активности останавливается после 5 минут простоя по умолчанию, при блокировке Windows
  и на паузе. Порог простоя меняется в разделе «Настройки».
- **История**: повторы одного окна раскрываются в список посещений. Категорию можно исправить
  для записи или запомнить правило для названия окна либо приложения. Поиск по всем дням ведёт
  к найденному отрезку на шкале, а клик по дате открывает календарь с отметками записей.
- **История буфера обмена**: скопированные тексты и программа, откуда их скопировали. Одинаковый текст
  хранится один раз. Листать можно из любого места клавишами **Ctrl+Alt+↑ / ↓**: справа снизу появляется
  плашка, выбранное кладётся в буфер, остаётся нажать Ctrl+V. Пароли из менеджеров паролей и похожие
  на пароль тексты не записываются; запись можно удалить, историю можно очистить целиком.
- **«Запомнить это»**: закладка на текущий момент с необязательной заметкой.
- **Вкладка «Система»**: нагрузка процессора и памяти, трафик по часам, самые нагруженные программы, диск, батарея.
- **Сравнение недель**: время по категориям и приложениям, выполнение целей, фильтр по рабочим часам в будни.
- **Настройки записи**: буфер можно отключить отдельно, исключить приложения, ограничить срок хранения
  и удалить записи за выбранные даты. Есть светлая, тёмная и системная темы.
- **Работа из трея**: закрытие окна не останавливает запись; при закрытом окне работает один небольшой процесс.
- **Языки**: русский и английский, выбираются автоматически по Windows и переключаются в программе.
  Новый язык добавляется одним файлом, см. [ui/i18n/README.md](ui/i18n/README.md).
- Экспорт дня в CSV, «забыть последние 10 минут», автозапуск вместе с Windows.

## Скачать

Возьмите `memory-log.exe` на странице [Releases](../../releases) и запустите. Windows может показать
предупреждение SmartScreen: файл не подписан сертификатом, нажмите «Подробнее → Выполнить в любом случае».
Нужен компонент WebView2 (есть в Windows 11 и в большинстве Windows 10).

## Приватность

- База — локальный файл SQLite в `%APPDATA%\app.memorylog.desktop`.
- Окна банков, менеджеров паролей и приватных вкладок браузера скрываются до записи в базу.
- Виден значок в трее, пауза в один клик. Скрытого режима нет.
- Записываются заголовки окон, а не содержимое. Нажатия клавиш не записываются.

Как всё устроено: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Синхронизация через Google Drive

Синхронизация выключена по умолчанию. Подключённые к одному аккаунту ПК могут читать историю окон,
закладки и правила категорий друг друга. Буфер обмена и системные показатели остаются на исходном ПК.
Файлы передаются по HTTPS без дополнительного шифрования со стороны Memory Log.

В сборке с синхронизацией на каждом ПК достаточно нажать **Подключить Google** и войти в один и тот
же аккаунт. Имя компьютера уже заполнено. Загрузка накопленной истории включается отдельным флажком.

### Подготовка сборки с входом в Google

Для публичного релиза с автообновлениями см. [настройку публикации](docs/PUBLISHING.ru.md).

Владелец приложения один раз включает Google Drive API в своём проекте Google Cloud, настраивает
экран согласия и создаёт OAuth-клиент типа **Desktop app** с доступом `drive.appdata`. Для сборки,
которую будут использовать разные люди, выберите аудиторию **External** и настройте публикацию
проекта.

Задайте `MEMORY_LOG_GOOGLE_CLIENT_SECRET` в окружении сборки. Возьмите значение
`installed.client_secret` из JSON для соответствующего клиента **Desktop app** и храните этот
файл вне Git. Следующая команда встраивает параметры настольного OAuth-клиента Memory Log:

```powershell
cargo build --release --manifest-path app/Cargo.toml --features google-sync-release
```

Для собственного проекта передайте `MEMORY_LOG_GOOGLE_CLIENT_ID` в окружении сборки. Обычная
локальная сборка работает без настроек OAuth.

Синхронизация работает в фоне, пока приложение запущено в трее. Удаление записей на исходном ПК
отражается на остальных. Отключение синхронизации на ПК сохраняет данные на Google Drive.
Для внешнего OAuth-приложения в режиме Testing Google выдаёт токены обновления на семь дней.

## Сборка из исходников (Windows)

1. [Rust](https://rustup.rs) (stable)
2. Visual Studio Build Tools с компонентом «Разработка классических приложений на C++»
3. WebView2 (в Windows 11 уже есть)

```bash
cargo test --workspace                                   # тесты логики и базы
cargo build --release --manifest-path app/Cargo.toml --features tauri/custom-protocol
                                                         # target/release/memory-log.exe
```

Для установщика и режима разработки поставьте Tauri CLI (`cargo install tauri-cli --version "^2"`),
затем `cd app && cargo tauri dev` или `cd app && cargo tauri build`.
Иконки: `cd app && cargo tauri icon путь/к/картинке.png`.

Режим сжатия «Очень сильное (.tar.zst)» в виджете автоматически сжимает PNG и JPEG с помощью JPEG XL без потерь, если это уменьшает размер, и восстанавливает исходные PNG/JPEG при распаковке. Установщики Windows включают утилиты JPEG XL. Для локальной release-сборки запустите `./tools/prepare-jpeg-xl.ps1` из корня проекта и держите полученную папку `codecs` рядом с `memory-log.exe`.

## Структура проекта

```
app/                 оболочка Tauri: окно, трей, горячие клавиши, команды
ui/                  интерфейс (HTML/CSS/JS) и переводы в ui/i18n/
crates/ml-core       чистая логика: сессии, сводка, категории, приватность
crates/ml-storage    SQLite и миграции
crates/ml-collector  источники данных Windows: активное окно, буфер обмена, нагрузка
config/              правила категорий
```
