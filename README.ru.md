# Memory Log

[English](README.md) · **Русский**

Локальная «память компьютера» для Windows: тихо записывает, чем вы занимались за день, и показывает
понятную сводку. **Всё хранится на вашем ПК.** Ничего не отправляется в сеть.

## Возможности

- **Сводка дня**: активное время, на что оно ушло (работа, общение, соцсети, игры…), главные занятия,
  ритм дня (перерывы, переключения между программами), цели на день, обзор недели.
- **История**: все окна за день с мгновенным фильтром и поиск по всем дням.
- **История буфера обмена**: скопированные тексты и программа, откуда их скопировали. Одинаковый текст
  хранится один раз. Листать можно из любого места клавишами **Ctrl+Alt+↑ / ↓**: справа снизу появляется
  плашка, выбранное кладётся в буфер, остаётся нажать Ctrl+V. Пароли из менеджеров паролей и похожие
  на пароль тексты не записываются; запись можно удалить, историю можно очистить целиком.
- **«Запомнить это»**: закладка на текущий момент с необязательной заметкой.
- **Состояние ПК**: нагрузка процессора и памяти, трафик по часам, самые нагруженные программы, диск, батарея.
- **Работа из трея**: закрытие окна не останавливает запись; при закрытом окне работает один небольшой процесс.
- **Языки**: русский и английский, выбираются автоматически по Windows и переключаются в программе.
  Новый язык добавляется одним файлом, см. [ui/i18n/README.md](ui/i18n/README.md).
- Экспорт дня в CSV, «забыть последние 10 минут», автозапуск вместе с Windows.

## Скачать

Возьмите `memory-log.exe` на странице [Releases](../../releases) и запустите. Windows может показать
предупреждение SmartScreen: файл не подписан сертификатом, нажмите «Подробнее → Выполнить в любом случае».
Нужен компонент WebView2 (есть в Windows 11 и в большинстве Windows 10).

## Приватность

- База — локальный файл SQLite в `%APPDATA%\app.memorylog.desktop`.
- Окна банков, менеджеров паролей и приватных вкладок браузера скрываются до записи в базу.
- Виден значок в трее, пауза в один клик. Скрытого режима нет.
- Записываются заголовки окон, а не содержимое. Нажатия клавиш не записываются.

Как всё устроено: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Сборка из исходников (Windows)

1. [Rust](https://rustup.rs) (stable)
2. Visual Studio Build Tools с компонентом «Разработка классических приложений на C++»
3. WebView2 (в Windows 11 уже есть)

```bash
cargo test --workspace                                   # тесты логики и базы
cargo build --release --manifest-path app/Cargo.toml --features tauri/custom-protocol
                                                         # target/release/memory-log.exe
```

Для установщика и режима разработки поставьте Tauri CLI (`cargo install tauri-cli --version "^2"`),
затем `cd app && cargo tauri dev` или `cd app && cargo tauri build`.
Иконки: `cd app && cargo tauri icon путь/к/картинке.png`.

## Структура проекта

```
app/                 оболочка Tauri: окно, трей, горячие клавиши, команды
ui/                  интерфейс (HTML/CSS/JS) и переводы в ui/i18n/
crates/ml-core       чистая логика: сессии, сводка, категории, приватность
crates/ml-storage    SQLite и миграции
crates/ml-collector  источники данных Windows: активное окно, буфер обмена, нагрузка
config/              правила категорий
```
